# PROP HUNTER NBA — 52 editierbare Mastervorlagen

Diese SVG-Dateien sind **datenfreie, mehrschichtige Master** im freigegebenen blau-goldenen Arena-Stil. Sie enthalten keine fest eingebauten Spieler, Wappen, Zahlen oder Quoten. Alle dynamischen Texte besitzen `data-field`; Fotos/Wappen besitzen `data-image-slot`. Der Spieler wird **ohne Rahmen** als transparente PNG-Ebene direkt in den Hintergrund eingefügt.

**Familien:** Single (21 Marktvarianten), Longshot (1), Ladder (2–6 Legs), Builder (2–6), Same Player (2–6), Cross Game (2–6), Combo/Multi (2–6), Lottery (2–6). Gesamt **52** SVGs. Siehe `manifest.json` für die Zuordnung der Builder-Profile.

**Sicherheit:** Nur verifizierte Buchmacherquoten. Eine Kombiquote darf niemals aus Einzelquoten erfunden werden. Datum/Uhrzeit nur vom echten Spiel. L5/L10/L15 und Modellwerte nur aus vorhandenen Daten. Settlement muss die Original-Telegram-Nachricht bearbeiten.

**Status:** Designmaster/QA, **noch nicht** in die produktive Telegram-Pipeline geschaltet. Die bisherigen JPGs in `card_templates/originals/` bleiben unverändert. Erst nach Datenadapter, Alpha-Foto-Validierung, PNG-Render-Test und visueller Freigabe aktivieren.
